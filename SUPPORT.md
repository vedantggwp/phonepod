# Support

phonepod is maintained as an open-source project. Public support happens through GitHub issues and pull requests.

Use GitHub issues for:

- reproducible bugs;
- installation or packaging failures;
- unclear documentation;
- format compatibility problems;
- focused feature requests.

Before opening an issue, please check existing issues and include the command, operating system, Python version, input format, and a minimal reproduction when possible.

Do not post private recordings, credentials, or proprietary audio in public support requests.
